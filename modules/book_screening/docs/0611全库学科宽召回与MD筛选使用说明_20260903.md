# 0611 全库学科宽召回与 MD 筛选使用说明

## 一、脚本和配置

- 全库宽召回：`scripts/stream_subject_recall_0611.py`
- 书目初筛和 MD 审核：`scripts/general_book_screening_pipeline.py`
- 学科配置目录：`configs/subject_recall/`

新增学科时复制一份学科配置，只修改：

- `subject_name`：中文学科名。
- `subject_slug`：英文目录名。
- `boundary`：该学科的别名、直接标签、相邻标签、强弱领域词、共同出现词组和排除短语。

算法代码不包含土木工程、心理学等固定学科判断。

## 二、全库宽召回

```bash
python3 scripts/stream_subject_recall_0611.py \
  --input-csv corpus_es_book_dedup_1451w_deduped_version0611.csv \
  --config configs/subject_recall/civil_engineering.json \
  --config configs/subject_recall/psychology.json \
  --output outputs/subject_broad_recall
```

每个学科输出：

- `{学科}_宽召回全集.csv`
- `{学科}_满足后续处理条件.csv`
- `{学科}_硬规则排除清单.csv`
- `{学科}_宽召回统计.json`

宽召回优先保证召回率。`strong_recall` 和 `weak_recall` 均保留，并记录命中渠道、字段和词语。

硬规则只判断后续能否处理：年份必须非空且不早于 2000 年；语言为简体中文或英文；文件为非影印版 PDF，或 `pdf_detail_type` 为空且格式为 EPUB；必须有 `parsed_path`；期刊类排除。

## 三、接入现有筛选

先将宽召回结果中的 `{学科}_满足后续处理条件.csv` 交给书目初筛：

```bash
python3 scripts/general_book_screening_pipeline.py metadata \
  --input-csv outputs/subject_broad_recall/civil_engineering/土木工程_满足后续处理条件.csv \
  --output outputs/civil_engineering_audit \
  --subject 土木工程 \
  --audit-track 辞海类 \
  --audit-all
```

没有学科分类树时不传 `--l1-config`。此时模型按学科相关性、正文结构、OCR 质量和知识点抽取适用性判断。

再对生成的 `MD审核试验样本.csv` 执行 `audit`，完成后执行 `materialize` 生成 PASS、REVIEW、DROP 三级结果。生产运行建议并发 50；访问源 OSS 的凭据只通过环境变量或安全包装脚本传入，不写入代码、日志和结果文件。
