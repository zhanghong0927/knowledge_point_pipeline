# 通用书籍 MD 筛选脚本说明

更新日期：2026-09-04  
适用脚本：`scripts/general_book_screening_pipeline.py`

## 1. 用途

本脚本用于从一个学科的 0611 字段书目中筛选适合抽取并挂载知识点的书籍，分为两个轨道：

- **辞海类**：判断正文是否反复呈现“词头 + 对应解释”的词典、辞典、百科或术语工具书结构。
- **其他重要书籍**：判断正文是否持续包含可脱离具体产品、软件或题目复用的概念、原理、方法、分类和工程关系。

两个轨道共用元数据硬门槛、语言和 OCR 检查、学科 L1 边界、断点续跑及三级输出，但正文结构判定规则不同。

## 2. 总体流程

```text
学科 0611 字段书目
-> 元数据硬过滤
-> 分为辞海类 / 其他重要书籍
-> 初筛分档
-> 定位 parsed_path 对应 MD
-> 分布式抽取正文片段
-> 大模型逐段判断
-> 程序复算并执行硬门槛
-> PASS / REVIEW / DROP
-> 生成总表和分级目录
```

## 3. 输入要求

输入为 UTF-8 CSV，至少包含：

```text
identifier、title、publicationyear、pdf_detail_type
distributionformat、language、parsed_path
```

建议同时保留：

```text
author、publisher、abstract、description、keywords
content_category、content_genre、usage_type、audience_level
subject1、subject2、subject3、documentpath、page_count
```

每个学科建议提供统一的边界附件 JSON，至少包含 `subject_name` 和 `boundary`。`boundary` 需要说明核心范围、允许的相邻领域和明确排除范围；可选的 `l1_nodes` 每个节点包含 `name、path、node_definition、node_boundary`。L1 只用于筛书时判断能否挂入学科大方向，不用于最终知识点的细粒度挂载。

```json
{
  "subject_name": "土木工程",
  "boundary": {
    "core_scope": "结构、岩土、桥梁、隧道、道路、市政与施工工程",
    "accepted_adjacent": ["建筑材料", "工程管理", "工程地质"],
    "excluded_scope": ["室内装饰", "纯计算机编程"]
  },
  "l1_nodes": []
}
```

`l1_nodes` 可以为空。为空时仍按明确边界判断学科相关性和知识抽取适用性，不因无法返回 L1 路径而降级。为兼容已有任务，原来的 `--subject` 与 `--l1-config` 参数继续可用。

## 4. 元数据硬门槛

以下任一条件成立，书目直接进入 DROP，不调用大模型：

1. `publicationyear` 为空或早于 2000 年。
2. 文件既不是 `pdf_detail_type=非影印版PDF`，也不满足“`pdf_detail_type` 为空且 `distributionformat=EPUB`”。
3. `language` 不是 `zh` 或 `en`。
4. `parsed_path` 为空。
5. 元数据明确显示为期刊、杂志单期或连续出版物。

正文中如果识别到明确的原始出版年份早于 2000 年，也会在 MD 阶段降为 DROP。电子版、扫描版或上传年份不算原始出版年份。

## 5. 辞海类初筛

当前代码按书名匹配：

```text
中文：辞海、词典、辞典、大词典、大辞典、百科、百科全书、大百科全书、图典、辞书、术语、名词、词汇
英文：dictionary、lexicon、encyclopedia、encyclopaedia、glossary、terminology、vocabulary、nomenclature
```

命中核心词后通常标记为 `strict_keep`。若题名同时出现习题、考试、研究、少儿、普及、图鉴等风险信号，则标记为 `review`，交给 MD 判断。

已处理两个典型误命中：

- “图典型”不作为“图典”命中。
- `dictionary learning` 不作为词典命中。

辞海候选优先按 `identifier` 去重，标识不同再按规范化标题去重。重复项不进入 MD 审核。

## 6. 其他重要书籍初筛

非辞海类书籍满足以下任一条件时标记为 `strict_keep`：

1. `content_genre` 为 `HIGHER_EDU_TEXTBOOK`、`STANDARD` 或 `HANDBOOK`。
2. `content_category=KNOWLEDGE_EXPOSITION`，且不属于明显风险书型。
3. 受众为 `ACADEMIC` 或 `PROFESSIONAL`，用途包含 `TEACHING` 或 `PROFESSIONAL_USE`，且不属于明显风险书型。

风险书型：

```text
COURSEWARE、POPULAR_SCIENCE、SOCIAL_COMMENTARY、K12_TEXTBOOK
BUSINESS_INSIGHT、GUIDE、EXAM_PREP、BIOGRAPHY、SELF_HELP、HISTORY
```

当前脚本默认将其余元数据合格书籍标记为 `review`。2026-09-04 机械全量任务采用更严格口径：**其他重要书籍只审核 `strict_keep`，初筛 `review` 不进入 MD 审核**。

## 7. MD 抽样与公共检查

默认从每本 MD 中分布式抽取 16 段，每段约 1,200 字，覆盖前部、中部和后部，并过滤明显的 Base64、超长机器串和无意义标签。

大模型逐段判断：

- 正文主语言是否为简体中文、英文或中英混合。
- 是否存在繁体正文主体或大量其他语言。
- OCR 是否出现乱码、重复、串栏、漏文或词头释义错配。
- 问题能否通过删除页眉页脚、HTML 标签、重复块等规则清洗。
- 内容是否符合学科明确边界；提供 L1 时再判断能否命中至少一个 L1 节点。
- 正文是否方便抽取可独立理解和复用的知识点。

只有完全无法判断能否通过时才使用 REVIEW。局部且可规则清洗的问题可以 PASS。

## 8. 辞海类 MD 判定

逐段结构标签：

```text
compact_entries       密集短词条
long_article          词头下的长篇百科解释
continuous_prose      普通连续章节正文
translation_pairs     双语对照词条
frontmatter_index     封面、目录、索引
unclear               无法判断
```

判定原则：

- 密集短词条、双语对照词条可以保留。
- 与明确词头对应的长篇百科解释可以保留。
- 不能因为个别片段是前言、索引或长解释就删除整本书。
- 正文主体是无词头的连续章节、论文或叙事文本时 DROP。
- 标题像辞典但正文没有稳定词条结构时不能 PASS。

模型必须返回全部片段的结构标签，程序再按比例复算最终等级，避免只依赖模型总评。

## 9. 重要书籍 MD 判定

逐段知识形态标签：

```text
general_knowledge              通用概念、原理、方法和关系
product_specific_procedure     特定产品或设备操作步骤
software_operation             特定软件菜单和操作
paper_experiment               单篇论文式实验内容
exercise_question              习题、试题和答案
catalog_table                  产品目录或参数罗列
biography_news_marketing       传记、新闻或营销内容
frontmatter_index              封面、目录、索引
invalid_text                   无法恢复的乱码或空内容
unclear                        无法判断
```

判定原则：

- 教材、标准、手册和系统性专著可以 PASS，但正文必须持续包含可复用知识。
- 特定软件、产品步骤、题库、论文实验、目录表格等占主体时 DROP。
- 少量操作步骤、习题、表格或局部 OCR 噪声不应覆盖整本书的系统性知识价值。
- 学科相关性或知识抽取适用性为低时直接 DROP。
- 模型给出 PASS，但相关性、适用性或 L1 命中不足时，程序降为 REVIEW。

## 10. 全文硬规则

除 16 段抽样外，程序还扫描全文信号。以下情况可直接 DROP：

- 明确原始出版年份早于 2000 年。
- 题目与答案结构占主体。
- 单篇论文或会议论文。
- 多作者独立研究章节合集。
- 正文主体为繁体中文或大量非中英文。
- 大面积不可恢复 OCR 错误。

期刊检测会在元数据阶段和 MD 正文阶段各执行一次。

## 13. 更换学科时需要替换的内容

Python 脚本、辞海结构标签、重要书籍知识形态标签和公共质量规则不需要按学科复制。每次处理新学科，只替换以下内容：

1. `--input-csv`：换成该学科的 0611 字段书目。输入应已按 `subject1` 主学科切分。
2. `--subject-config`：换成该学科的统一边界附件。附件中的 L1 可以为空；需要同时验证大方向挂载时再补充宽口径 L1。
4. `--output`：必须使用该学科独立输出目录，不能与其他学科共用 `progress.jsonl`。
5. `--cache-dir`：可以使用学科独立缓存，也可以共用按 OSS URI 哈希命名的缓存目录。

通用命令模板：

```bash
python3 /mnt/nas2/home/wangqiyuan/general_book_screening_20260903/bin/general_book_screening_pipeline_v7_subject_boundary.py audit \
  --input-csv '{该学科0611字段书目.csv}' \
  --output '{该学科独立输出目录}' \
  --subject-config '{该学科边界附件.json}' \
  --workers 50 \
  --sample-count 16 \
  --chunk-chars 1200 \
  --cache-dir '{MD缓存目录}' \
  --source-oss-endpoint 'http://oss-cn-hangzhou-zjy-d01-a.ops.cloud.zhejianglab.com'
```

学科边界附件决定模型如何判断“是否属于该学科”；可选 L1 决定如何判断“能否挂入学科大方向”。例如处理经济学时，不能继续使用机械工程边界或 L1，否则会产生跨学科误判。

以下规则默认跨学科共用，无需替换：

- 年份、语言、文件类型、MD 路径和期刊硬门槛。
- 辞海类标题关键词及词条结构规则。
- 其他重要书籍的教材、标准、手册等初筛规则。
- OCR、繁体、非中英文、论文集、习题集和软件操作等质量规则。
- PASS、REVIEW、DROP 输出格式和断点续跑逻辑。

如果某学科存在特殊边界，应优先写入该学科的 `node_definition` 和 `node_boundary`，不应复制并修改一份 Python 脚本。确实需要学科专属例外时，应另建配置字段并保留触发原因。

## 14. 当前限制

1. 辞海标题词表尚未加入“字典、词表、cyclopedia”等新增建议词；修改时需要同时同步独立辞海初筛脚本和本通用管线。
2. “其他重要书籍排除初筛 REVIEW”目前是本轮运行口径，不是独立命令行参数；复用时需要先生成并过滤审核清单。
3. 模型结果不能代替人工抽检。规则调整后，应先用历史人工样本回归，再用未参与调参的新样本独立抽检。
4. 当前筛书只使用宽边界及可选 L1 判断大方向，最终知识点仍需使用完整分类树挂载。
