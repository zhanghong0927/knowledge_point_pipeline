## 4. 上传与下载文件

以下命令在本地Windows PowerShell运行，不是在远程Linux终端运行：

```powershell
# 下载工具包到本机D:\七月工作。
scp "wangqiyuan@10.200.48.146:/mnt/nas2/home/wangqiyuan/toolkits/book_screening_toolkit_20261008.zip" "D:\七月工作\"

# 上传单个文件。执行前将本地示例路径替换为实际文件。
scp "D:\七月工作\自己的文件.csv" "wangqiyuan@10.200.48.146:/mnt/nas2/home/wangqiyuan/toolkits/"

# 查看远程文件大小和更新时间。
ssh wangqiyuan@10.200.48.146 "ls -lh /mnt/nas2/home/wangqiyuan/toolkits/book_screening_toolkit_20261008.zip"

# 核对下载文件与远程文件SHA256，两者应完全相同。
Get-FileHash -Algorithm SHA256 -LiteralPath "D:\七月工作\book_screening_toolkit_20261008.zip"
ssh wangqiyuan@10.200.48.146 "sha256sum /mnt/nas2/home/wangqiyuan/toolkits/book_screening_toolkit_20261008.zip"
```

SCP同名目标可能被覆盖，上传前先检查目标；不要覆盖正式交付或正在运行的输入。大书库和全量结果保留在NAS，仅按需下载工具包、统计、报告或少量样本。

## 5. 常见连接问题

| 现象 | 排查方向 |
| --- | --- |
| 找不到`ssh`或`scp` | 检查本机OpenSSH客户端是否安装并位于PATH |
| 连接超时、无法访问 | 检查是否能接入公司内网；需要时使用公司允许的VPN/网络路径 |
| `Connection refused` | 检查目标IP、端口及SSH服务；不要自行重启共享开发机 |
| `Permission denied (publickey,password)` | 网络已连到SSH，但认证未通过；核对用户名和获授权的密钥/账号权限 |
| `REMOTE HOST IDENTIFICATION HAS CHANGED` | 先确认主机是否确实更换及新指纹；不要直接删除校验记录或关闭校验 |
| `No such file or directory` | 区分Windows路径与Linux路径，检查NAS挂载和绝对路径；不要把`/mnt/nas2/...`当成Windows本地目录 |

本地Windows可检查端口连通性：

```powershell
Test-NetConnection 10.200.48.146 -Port 22
```

端口可达不等于认证成功，认证成功不等于具有所有目录的读写权限。VS Code中的远程连接也不意味着其他终端或Codex会自动继承其连接状态。
