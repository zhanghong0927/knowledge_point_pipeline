# 通用词条名双层清洗脚本

## 文件说明

- `01_name_title_quality.py`：第一层通用词条名质量清洗。审核 `name` 和 `knowledge_point`，输出 `keep/review/drop`；只修复原字符串中可以明确截取的连续片段，不补译、不新增词语。
- `02_subject_scope_filter.py`：第二层学科范围筛选。读取第一层的 Keep 完整记录，按可插拔的学科与 L1 边界配置输出 `keep/review/drop`，采用宽召回口径。
- `scope_configs/`：现有学科配置示例。更换学科时只需替换配置，不必修改脚本。

两套脚本均只使用 Python 标准库，建议 Python 3.10 及以上版本。

## 输入要求

支持 JSON 数组、JSONL 和 `.gz` 压缩输入。每条记录建议包含唯一 `id`，并包含以下字段之一或两者：

```json
{"id":"1","name":"数据格式","knowledge_point":"Data format","definition":"定义文本"}
```

- `name`、`knowledge_point` 至少一个非空；若两者均非空，第一层会分别审核并检查对应关系。
- 可选上下文字段为 `definition`、`description`、`explanation`。
- 原记录的其他字段会保留在 `*_full.jsonl` 输出中。

## 第一步：通用词条名质量清洗

Windows PowerShell 示例：

```powershell
python .\01_name_title_quality.py `
  --input "D:\data\input.jsonl" `
  --out-dir "D:\data\stage1" `
  --api-url "http://你的服务地址/v1/chat/completions" `
  --model "qwen3.8-27b" `
  --no-auth `
  --workers 200 `
  --batch-size 20 `
  --resume
```

默认 `--context-chars 0`，即只按词条名判断。需要结合定义、描述或解释时加入：

```powershell
--context-chars 2000
```

主要完整记录输出：

- `llm_name_title_format_keep_full.jsonl`
- `llm_name_title_format_review_full.jsonl`
- `llm_name_title_format_drop_full.jsonl`
- `llm_name_title_format_repair_audit.jsonl`
- `llm_name_title_format_report.json`

技术失败或模型返回不完整的记录进入 Review，不按内容 Drop。中断后使用同一输入、输出目录和参数加 `--resume` 续跑。

## 第二步：学科范围筛选

```powershell
python .\02_subject_scope_filter.py `
  --input "D:\data\stage1\llm_name_title_format_keep_full.jsonl" `
  --out-dir "D:\data\stage2" `
  --scope-config ".\scope_configs\civil_engineering.scope.json" `
  --api-url "http://你的服务地址/v1/chat/completions" `
  --model "qwen3.8-27b" `
  --no-auth `
  --workers 200 `
  --batch-size 20 `
  --context-chars 2000 `
  --resume
```

主要完整记录输出：

- `subject_scope_keep_full.jsonl`
- `subject_scope_review_full.jsonl`
- `subject_scope_drop_full.jsonl`
- `subject_scope_report.json`

第二层仅处理第一层的 Keep 记录。`in_scope` 对应 Keep，`uncertain` 对应 Review，只有明确没有目标学科用途的 `out_of_scope` 才对应 Drop。

## 新建学科配置

复制任一 `scope_configs/*.json` 后修改以下结构：

```json
{
  "subject": "学科中文名",
  "subject_definition": "学科总体定义",
  "subject_boundary": "总体纳入和排除边界，建议明确采用宽召回口径",
  "l1_nodes": [
    {
      "name": "L1 节点名",
      "definition": "节点定义",
      "boundary": "该节点的纳入与排除边界"
    }
  ]
}
```

`subject`、`subject_definition`、`subject_boundary` 和每个 L1 节点的三个字段均不能为空；L1 节点名称不能重复。

## 建议验证

正式全量运行前先做小样本：

```powershell
python .\01_name_title_quality.py --input "D:\data\input.jsonl" --out-dir "D:\data\test_stage1" --api-url "http://你的服务地址/v1/chat/completions" --model "qwen3.8-27b" --no-auth --limit 100 --workers 10
```

检查报告中的输入数与 Keep、Review、Drop 总数是否一致，再启动全量任务。全量完成后还应核对输入 ID 集合与三档输出 ID 集合是否一致。
