# 定性知识可用性模式

使用 `dictionary_md_audit.py --knowledge-value-mode` 启用。

## 本版判断口径

- 不按非知识型词头比例、固定词头数量或人物作品类型分级，也不因为比例超过某个值自动进入 REVIEW。
- PASS：主体为可用的学科词条，能够提供可靠的概念、特征、关系、方法或事实；人物、作品等有明确学科解释时也可通过。
- DROP：主体不适用，例如纯名单、普通语言记忆与考试词汇练习、缺少学科知识的材料，或不合格语言、系统性不可恢复的解析损坏。
- REVIEW：主体混合、局部损坏或证据不足。提供待核查片段；需要补充上下文或抽样后再决定。
- 繁体主体、实质非中英文和多语种词头继续按语言门槛排除。

## 抽样与证据

采用分散正文抽样和词头锚定抽样，识别 Markdown 标题及部分非标题词头，并附上前后文。排除明显作者简介等非正文，避免高度重叠的片段重复计数。自动判断的非正文范围仍可能不完整，由模型继续区分。

对长百科词条、词条内部例子和取样截断单独说明，不能仅因一个片段里没有词头而认定源文缺失。模型按片段返回角色、结构、语言和问题依据，并给出 2 至 4 个实际词头与释义锚点。程序核对锚点是否在该片段或附带原文上下文中；未匹配的例子单独记录，不计入有效证据。

使用服务的 `/tokenize` 核算请求长度，为输出预留空间。必要时先裁剪附加上下文，再缩短核心片段；实际发送的样本及 token 信息保存在每本 `progress.jsonl` 记录的 `input_samples`、`context_budget` 中。服务不提供分词接口时采用保守估算。

这仍是抽样审查，不表示逐页检查或整书无错。REVIEW 是待补证据状态。可选的 PASS 反证复核只处理可疑 PASS，并且只允许将 PASS 降为 REVIEW，不会自动新增 DROP。

## 运行

```bash
python3 dictionary_md_audit.py all \
  --root /path/to/input \
  --config /path/to/audit_config.json \
  --output /path/to/new_result_directory \
  --api-url http://your-service/v1/chat/completions \
  --model /path/to/model \
  --knowledge-value-mode --pass-challenge \
  --workers 16 --parallel-subjects 3 \
  --max-tokens 5500 --timeout 240 --retries 2 \
  --skip-priority-workbook --symlink-classified
```

复用已经完成的第一轮结果时，不必重跑 `run`：

```bash
python3 dictionary_md_audit.py challenge \
  --root /path/to/input --config /path/to/audit_config.json \
  --output /path/to/existing_result_directory \
  --api-url http://your-service/v1/chat/completions --model /path/to/model \
  --workers 16 --challenge-sample-count 8 --max-tokens 2500

python3 dictionary_md_audit.py materialize \
  --root /path/to/input --config /path/to/audit_config.json \
  --output /path/to/existing_result_directory \
  --pass-challenge --skip-priority-workbook --symlink-classified
```

反证阶段单独保存到各学科的 `模型反证复核/challenge_progress.jsonl`。触发后结果缺失时，`materialize --pass-challenge` 会报错，不会静默保留首次 PASS。维持 PASS 需要至少三个不同样本中各有一条可回查的实质学科知识证据；排名、趣闻、传记事实、普通查词、名言出处和名单不能单独作为通过证据。

这里三学科最多合计 48 个工作线程。只跑一个学科时可以单独调整 workers。

修改策略后使用新的输出目录。脚本检查断点策略，避免把旧版 progress 当成本版结果续跑。保持策略、输入与抽样参数不变时可继续相同目录。

旧参数 `--max-nonknowledge-headword-ratio`、`--drop-nonknowledge-headword-ratio`、`--min-headword-evidence` 仅为兼容旧命令保留，在定性模式下不参与分级。定性模式与旧版 `--strict-text-quality` 不能同时启用。

## 输出

CSV 与三级文件夹继续生成。新增 `knowledge_value_policy`、`knowledge_value_assessment`、`unverified_knowledge_examples` 字段，记录本版策略、主体判断、原文例子和未核实的引用。启用反证复核时还会新增 `pass_challenge_reasons`、`pass_challenge_recommendation`、`pass_challenge_strong_evidence_count` 和完整反证 JSON。

`knowledge_value_evidence_count` 在本模式中表示已保留的知识例子数；旧词头比例列为空，不能再按词头比例解释。原始模型响应、实际发送样本与最终分级均保留在 progress 中。
