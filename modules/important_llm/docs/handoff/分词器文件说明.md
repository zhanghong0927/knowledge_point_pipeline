# 附带分词文件

交付包 `data/tokenizers/qwen3.8-27b/` 仅包含 `tokenizer.json`、`tokenizer_config.json`、`chat_template.jinja`。这是当前模块使用的 Qwen3.8-27B 分词/模板文件，不含模型权重；文件哈希列入 PACKAGE.json，运行时另记录 tokenizer 指纹。

这些文件属于上游模型资产，原许可仍适用，本项目不改变其许可。依赖库同样遵循各自的上游许可；本包不把第三方资产声明为本项目原创代码。调用方若采用其他模型或不同部署模板，必须取得对应版本的分词文件并替换配置，不能认为同模型系列的 tokenizer 必然一致。

分词文件是可复现实例的必要输入，不是对任意服务“准确计费”的保证。完整请求还受服务端模板和参数处理影响；服务实际 usage 与本地计数分别记账。
